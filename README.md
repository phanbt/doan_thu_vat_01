# Đoán Tên Con Vật

Trò chơi đoán tên con vật bằng tiếng Việt cho bé từ 5 đến 9 tuổi.

- Mỗi lượt hiện một hình con vật và tên của nó, bị ẩn 3 chữ cái.
- Bé bấm vào các ô chữ cái để điền vào chỗ trống, rồi bấm **Kiểm tra**.
- Đếm số câu đúng và sai; chơi bao nhiêu lượt cũng được.
- Nút **Dừng chơi** để xem kết quả, nút **Chơi lại từ đầu** để bắt đầu lại.
- Nút **Đèn ngủ** để chuyển sang màn hình tối, dịu mắt.
- Có 55 con vật.

## Cách chơi

Mở file `index.html` bằng trình duyệt, không cần cài đặt gì.
